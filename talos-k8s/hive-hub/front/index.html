TunaOS Hive Constellation

A private kubestellar/hive hub. Each hive below maintains one subject area of the tuna-os organisation, so its agents work a focused backlog instead of competing across unrelated repos.

Hives

tunaos

The operating system — bootable container images, the BuildStream desktop build, installers, bootc tooling, branding, and OS package publishing.

hive.tunaos.org

reef

Applications and their distribution — GTK/libadwaita and Rust desktop apps, editors, VM and terminal tools, app indexes and Flatpak distribution.

reef.tunaos.org
