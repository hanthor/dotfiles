# shell_dotfiles

**Unit:** `chezmoi` (`units/chezmoi.sh`; see [Units](../units.md))  
**Tags:** `dotfiles`, `shell` (`just apply-tags shell` runs `unit:chezmoi`)  
**Secrets needed:** No  
**Runs on:** All machines with `chezmoi` installed (`core_brews`)

No longer an Ansible role: the shell, prompt, multiplexer and terminal configs are chezmoi-managed files under `home/` (`.chezmoiroot` points chezmoi there).

## Files (source in `home/`)

| Target | Source |
|---|---|
| `~/.bashrc`, `~/.zshrc`, `~/.inputrc`, `~/.tmux.conf` | `dot_bashrc`, `dot_zshrc`, `dot_inputrc`, `dot_tmux.conf` |
| `~/.zprofile` | `dot_zprofile.tmpl` (flatpak path on desktops) |
| `~/.config/shell/aliases.sh` | `dot_config/shell/aliases.sh.tmpl` |
| `~/.config/fish/conf.d/aliases.fish` | `dot_config/fish/conf.d/aliases.fish.tmpl` |
| `~/.config/fish/config.fish`, `~/.config/starship.toml` | `dot_config/fish/config.fish`, `dot_config/starship.toml` |
| `~/.config/ghostty/config` | `dot_config/ghostty/config` (inert on headless hosts) |
| `~/.config/shell/ghostty.terminfo` | `dot_config/shell/ghostty.terminfo`, compiled into `~/.terminfo` by `.chezmoiscripts/run_after_10-ghostty-terminfo.sh` (skips if `tic` is missing) so SSH from Ghostty keeps ncurses apps working |

## Template data

`home/.chezmoi.toml.tmpl` (regenerated by `apply --init`) provides `machine` and `is_desktop` from the unit. Desktop classification uses `DOTFILES_IS_DESKTOP`, then the host's `is_desktop` override, then the `desktop` group in `inventory.yml`; it fails rather than guessing if the classification cannot be read. `home/.chezmoidata.yaml` provides `user_name`, `user_email` and `alias_groups`, the single source for the bash/zsh and fish aliases. Add a plain alias there, not in the templates.

## Adding a file

Put it under `home/` using chezmoi names: `dot_` for a leading dot, `.tmpl` suffix to template it, `private_`/`executable_` for modes. chezmoi never deletes files it does not manage.

## Fleet aliases

| Alias | Expands to |
|-------|-----------|
| `dots` | `cd ~/.local/share/dotfiles && just apply-nosecrets` (git pull + `--skip-tags secrets`) |
| `dots-apply` | `cd ~/.local/share/dotfiles && git pull --ff-only && just apply` (full, with BW unlock) |
| `dots-edit` | open the repo in `$EDITOR` |

In fish these are abbreviations (`abbr`), not aliases.

## Notes

- Shell secrets (`~/.config/shell/secrets.sh`, `~/.config/fish/conf.d/secrets.fish`) are written by the [`shell-ai` unit](shell_ai.md), not here.
- One failing file does not stop the rest: the unit runs `chezmoi apply --init --keep-going --force --no-tty`. This overwrites managed files even when locally edited; back up and review existing dotfiles before adoption. See [Units](../units.md#chezmoi).
- The `atuin` and `secrets` tags apply only `~/.config/atuin/config.toml` through chezmoi, without running its scripts or overwriting other managed files. When combined with a tag requesting full chezmoi apply (such as `shell` or `git`), the full apply takes precedence.
